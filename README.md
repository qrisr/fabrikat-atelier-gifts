# Fabrikat Atelier Gifts

Here's what we're building:

Fabrikat Gift Atelier is a B2B gifting app for Swiss SMEs that want to send high-quality, personalized Fabrikat year-end gifts to employees, clients, or partners. Office managers and HR teams choose a curated gift set, adjust the theme, budget, packaging, card, and approved personalization, then request a quote for Fabrikat to review.

Create the premium brand shell and navigation

Build the core application layout and navigation structure for Fabrikat Gift Atelier. We need a high-end Swiss design aesthetic that matches our brand—clean typography, generous whitespace, warm minimalist neutrals, and a premium, analog feel. Create a responsive sidebar navigation that allows office managers and HR teams to transition smoothly between the main areas of the app: the Campaign Dashboard, the Gift Templates gallery, the Recipient Manager, and the Quote Review screen. At the top or bottom of the sidebar, display a clear company workspace selector or indicator showing the active company name. If a screen is currently empty, show a beautifully styled placeholder state with a clear call-to-action button that matches our premium brand tone.

How to check this worked:
- You see a beautiful, high-end Swiss design aesthetic featuring warm neutrals, minimalist typography, and the Fabrikat Gift Atelier logo.
- You can use the sidebar to seamlessly switch between the Campaign Dashboard, Gift Templates, Recipient Manager, and Quote Review screens.
- The sidebar clearly displays the current user's company name and an active workspace indicator.
